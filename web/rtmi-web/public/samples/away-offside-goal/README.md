# Synthetic away offside goal

Eight original schematic PNG frames for testing a goal scored from an offside position.

- **Away team:** blue Bulawayo Eagles, attacking right-to-left toward the home goal.
- **Home team:** lime Harare Lions, defending the goal on the left.
- **Goalkeeper:** the home keeper wears gold to distinguish the goalkeeper from outfield players.
- **Sequence:** the attacker is beyond the second-last defender when the through-ball is played, runs onto it, and puts the ball in the net. The defender reference line is shown at the pass.

Use `frame-01.png` through `frame-08.png` in order, or select this scenario in the dashboard sample picker. The goal is shown as scored in play; assess the supplied frames for the offside review. Synthetic artwork only; not real match footage or a real-world VAR benchmark.
