# Synthetic away attack

Eight original, schematic PNG frames for testing the RTMI video-referee image input and the dashboard playback controls.

- **Away team:** blue Bulawayo Eagles, attacking from right to left.
- **Home team:** lime Harare Lions, defending the goal on the left.
- **Goalkeeper:** the home keeper wears gold to distinguish the goalkeeper from outfield players.
- **Sequence:** away build-up, forward pass, shot, home goalkeeper blocks and gathers.
- **Use:** load via the dashboard's **Load Synthetic Sample** button, or attach `frame-01.png` through `frame-08.png` in order as Foundry image inputs.

This is synthetic stick-figure artwork. It is not match footage and does not demonstrate reliable real-world referee decisions.
